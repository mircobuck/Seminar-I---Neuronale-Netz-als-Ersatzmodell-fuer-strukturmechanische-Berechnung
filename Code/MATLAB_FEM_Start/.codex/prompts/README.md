# Prompt-Vorlagen

Hier liegen wiederverwendbare Aufträge. Neue Vorlagen aus [_template.md](_template.md) ableiten und mit englischen Namen in kebab-case speichern.

Vor der Verwendung alle mit `TODO:` markierten Eingaben ausfüllen. Relevante Rollen unter [../agents/](../agents/) und Skills unter [../skills/](../skills/) ausdrücklich per Pfad nennen. Ein Prompt beschreibt den konkreten Auftrag; ein Skill den wiederverwendbaren Ablauf; eine Rolle die Zuständigkeit.

Die Markdown-Dateien sind Vorlagen zum Lesen oder Kopieren. Ihre Ablage registriert keine zusätzlichen Codex-Befehle.
