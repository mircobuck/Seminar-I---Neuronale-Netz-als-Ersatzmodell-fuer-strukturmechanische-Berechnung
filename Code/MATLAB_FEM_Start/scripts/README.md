# Hilfsskripte

Hier können Skills und Agent-Rollen gemeinsam genutzte Hilfsskripte ablegen. Beim Setup wurde kein ausführbares Skript und keine Laufzeitumgebung hinzugefügt.

Neue Skripte mit englischem Namen in kebab-case benennen. Je Skript Zweck, Laufzeit und Abhängigkeiten, Aufruf aus dem Projektwurzelordner, Ein- und Ausgaben sowie mögliche Dateiveränderungen dokumentieren.
